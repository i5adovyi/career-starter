# Search and shortlist

1. Read the confirmed profile and source configuration in `local/`.
   Role, location, working pattern and genuine non-negotiables must come from
   the candidate. Do not inherit criteria from another candidate or profession.
2. Run `python career.py search`. Report the run time, usable sources, failures
   and count of results. Public feed support is finite: a search is not a
   complete survey of the market.
3. Review promising descriptions against the profile. Preserve the original
   URL, source and full description in the application context when available.
   Treat dates, salary, location and remote eligibility as unknown when the
   source does not establish them.
4. Separate three questions: does the role interest the candidate, does their
   evidence match its requirements, and are its employment constraints
   compatible? A keyword score is a shortlist aid, not proof of eligibility.
5. Explain the strongest few matches in plain language: strongest evidence,
   real gaps, unresolved conditions, and a useful next action.

Do not reject every vacancy with an unknown salary or an ambiguous requirement
unless the candidate made that a firm rule. Do not imply that “remote” means
worldwide; verify restrictions in the description or employer's listing.
Where the candidate is considering a career change, separate demonstrated
transferable skills from experience still to gain.

If network access is unavailable, report the affected sources and work from
candidate-provided links/descriptions or existing saved results. Say when a
result is saved or stale. Never convert a fetch failure into “no vacancies”.

An assistant may use its available search tools to broaden discovery, retaining
real URLs and evidence. Do not promise a provider integration or unattended
browser automation that the current environment does not have. Respect source
access restrictions; do not request credentials to scrape private accounts.

Search is invoked manually. Set up recurring searches only if the candidate
requests them and a supported scheduler is available. Creating a shortlist
does not authorize applications, recruiter messages, or CV uploads.
